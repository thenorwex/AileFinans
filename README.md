# AileFinans

Aile bütçesi ve finans takip uygulaması.

- Harcama ve gelir
- Aile üyeleri
- Hesaplar ve kartlar
- Araç ve kilometre
- Faturalar
- Sağlık harcamaları
- Borç/alacak
- Yatırımlar
- Çoklu para birimi
- Fotoğraf/fiş
- Raporlar

Teknoloji: SwiftUI + SwiftData. İlerleyen aşamada iCloud/CloudKit, Face ID, bildirimler ve yatırım fiyat API entegrasyonu eklenecek.
